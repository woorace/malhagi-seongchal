# 말하기 성찰일지

중학교 2학년 국어 「듣기·말하기 성찰하기」 단원 수업 자료입니다.
성취기준 [9국01-11] 듣기·말하기 과정을 점검하고 듣기·말하기의 어려움을 효과적으로 조정한다.

**바로 열기 → https://woorace.github.io/malhagi-seongchal/**

## 네 단계

1. **나의 목표** — 발표 성향 검사(20문항)를 하고, 처방전에서 이번에 꼭 지킬 것 하나를 고릅니다.
2. **말하기 계획** — 3P(목적·청중·자리)와 말하기 불안을 점검하고, 계획 카드를 만들어 나눕니다.
3. **1~3분 말하기** — 대본을 쓰면 핵심어 세 개를 뽑아 발표 자료를 만들고, 발표 직후 바로 점검합니다.
4. **성찰하기** — 청중과 피드백을 주고받고, 문제 → 원인 → 해결로 성찰합니다.

## 개인정보

학생이 쓴 내용은 **각자의 브라우저에만** 저장되며 서버로 전송되지 않습니다.
제출은 학생이 직접 내려받은 파일이나 복사한 텍스트로 이루어집니다.
